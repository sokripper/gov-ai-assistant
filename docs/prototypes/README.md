# 政府侧 AI 助手平台 · 交互原型交接说明

打开方式：浏览器直接打开 `index.html`（依赖同目录下的 `logo-梵行.svg` 与 `assets/` 本地素材，无需服务端）。
目标视口：桌面 Web，基准 1440×900；适配目标为 1920×1080、1440×900、1366×768、1280×720、1024×768。

> 本原型用于需求验证与评审演示，不作为生产前端源码。生产前端建议按 React + TypeScript + Vite + Ant Design 重建。

## 一、本期能力

### AI 工具（5 个）

| 分类 | 工具 | 原型入口 |
|---|---|---|
| 文本处理 | 文本优化与检查 | 文本型工作台 |
| 文档处理 | 文档速读 | 文件型工作台 |
| 数据处理 | Excel 统计与图表 | 文件型工作台 |
| 识别转换 | 图文识别（OCR） | 文件型工作台 |
| 识别转换 | 录音转文字 | 文件型工作台，可继续生成会议纪要 |

### AI 助手（6 个）

| 分类 | 助手 | 已贯通流程 |
|---|---|---|
| 内容创作 | 政务材料写作助手 | 填写要素 → 生成初稿 → 多轮修改 → 输出前检查 |
| 内容创作 | 公众号图文排版助手 | 导入审定正文与实拍图 → 生成标题与文章专属视觉基调 → 输出常规图文或故事动漫长图 |
| 研究分析 | 产业与政策研究助手 | 输入研究命题 → 自动检索公开资料 → 交叉核验 → 生成深度研究初稿 → 人工核对依据 |
| 研究分析 | 运营数据分析助手 | 导入 Excel/CSV → 指标与图表 → 分析结论 → 继续追问 |
| 策划事务 | 活动与宣传策划助手 | 输入主题与硬性条件 → 生成创意玩法 → 选定一个主方向 → 正式工作方案 → 完整性检查 |
| 策划事务 | 会议纪要助手 | 录音/速记稿 → 转写确认 → 纪要与待办 → 人工确认 |

### 后置能力

外部公众号持续监控、全网实时监控、Seedance 文章转视频、政策一致性审核、保密与敏感信息审核、民生诉求自动答复、文件对比、表格抽取和多语翻译均以占位卡展示，不进入本期交付。

## 三、当前 Demo 已贯通的状态流

| 起点 | 实际可演示流转 | 刷新后 |
|---|---|---|
| 知识库问答 | 按关键词和检索范围命中样例；无命中时阻止无依据生成；答案和引用可携带到材料写作 | 恢复初始样例 |
| 政务材料 | 要素表单生成对应初稿；对话修改会更新右侧文稿；输出前检查提示确定性问题和人工复核边界 | 恢复初始样例 |
| 活动与宣传策划 | 输入任务、传播目标、平台资源和不可编造内容；生成 3 个创意玩法方向，单选一个主方向或整批换新，再形成含三阶段安排、内容矩阵、任务分工与风险控制的正式方案 | 恢复重点会议宣传示例 |
| 产业与政策研究 | 用户只需给出研究命题、目的和方向；系统模拟检索 5 个政府公开来源，区分规划目标、历史数据和分析判断，生成带可点击依据的深度解读范文 | 恢复“东西湖十五五”样例 |
| 公众号图文排版 | 首屏先选择常规图文/故事长图和视觉气质，再紧凑导入审定正文与实拍图。常规图文进入大标题、小标题、视觉方向与首图编辑，切换方向会同步改变首图；故事长图先生成标题/对白可编辑的草图，确认后再进入图字一体生成。内置“梵行科技调研”一体化长图效果稿和完整 Seedance 动效 | 恢复初始样例，浏览器释放用户上传图片的临时地址 |
| 运营数据分析 | 选择 Excel/CSV 或载入示例；生成指标、趋势和建议；支持基于本次数据继续追问 | 恢复初始样例 |
| 录音转文字 | ASR 结果可携带到会议纪要，作为已载入转写稿继续生成 | 恢复初始样例 |
| 上传文档 | 排队 → 解析中 → 生效/失败；生效文档进入列表、详情和问答样例，失败项可重试 | 恢复初始样例 |
| 文档治理 | 搜索、组合筛选、启停、删除、批量停用、失败重试、切片停用均有状态变化 | 恢复初始样例 |
| 最近会话 | 可恢复对应工作台，并支持重命名、二次确认删除 | 恢复初始样例 |

## 五、生产接入点

配套 Codex Skill：`$CODEX_HOME/skills/gov-wechat-visual-production`。该 Skill 固化了首屏分流、正文与实拍图锁定、大标题/小标题编辑、长图草图确认、Seedream 图字一体生成、OCR 复核、成图改字重生成和 Seedance 完整动效的工作规则。

| 位置 | 原型函数 | 正式实现 |
|---|---|---|
| 知识问答 | `qaSend()` | VikingDB 检索 + 模型答案 + 引用定位 + 无命中拦截 |
| 单项工具 | `wbRun()` / `ftRun()` | Codex 任务编排 + 文档解析/OCR/ASR/图片服务/规则工具 |
| 通用写作 | `startAssistant()` / `wSend()` | 异步任务、流式输出、文稿版本与可定位修改 |
| 产业与政策研究 | `startResearch()` / `researchSourcesPanel()` | 按命题拆解问题，检索政府公开资料并交叉核验；保存来源快照、引用位置、事实口径和推演结论 |
| 活动与宣传策划 | `startPlanIdeation()` / `planDirectionPanel()` / `generatePlanDraft()` | 区分硬信息与创意空间，生成可选玩法并组合为正式方案；人员、日期、责任单位和统计数据必须由用户确认 |
| 输出前检查 | `runDraftCheck()` | 确定性规则 + 风险提示；最终结论必须人工确认 |
| 公众号图文排版 | `wxGenerateArticle()` / `wxBuildVisualStyles()` / `wxBuildSections()` / `wxStoryScenes()` / `wxUpload()` | 审定稿解析、可溯源大标题与小标题、视觉简报、常规图文参数化排版；故事长图先保存可编辑草图，确认后提交 Seedream 图字一体生成并做 OCR 对照，Seedance 完整动效随同一成稿呈现；不得修改审定原文或用生成图冒充真实现场 |
| 运营分析 | `dataRun()` / `dataFollow()` | Excel 解析、指标计算、图表数据与基于同一数据集的追问 |
| 会议纪要 | `mRun()` | ASR 转写 + 结构化抽取 + 待办确认 |
| 知识库治理 | `qPush()` / `chToggle()` | 上传、解析任务、VikingDB 索引同步与状态推送 |

## 六、分辨率策略

- `≥1280px`：完整侧边导航和桌面多栏布局。
- `1024–1279px`：侧边导航收为图标栏；公众号创作主区与预览区缩窄；数据工作台控制最小宽度；文档表格收起低优先级列。
- `<1024px`：不在本桌面原型验收范围内；如需移动端或平板端，应单独设计。公众号页面中的手机视图是“内容预览”，不是系统移动端适配。

## 七、原型边界

- 除“梵行科技调研”公开文章验证案例外，其余示例数据、单位名和文号均为虚构；该案例中的 AI 图片使用泛化虚构人物，不代表文中真实人员。
- 产业与政策研究默认不要求用户上传文件；当前“东西湖十五五”范文基于 5 个政府公开来源制作，正式版需实时检索、留存来源快照，并由编辑人员终审。
- 活动与宣传策划使用用户提供的历史方案提炼正式结构，但不把其中的人员名单、内部分工和未确认日期写入公开 Demo；模型只生成栏目、玩法、内容产品和传播节奏。
- 公众号页面会真实读取用户在浏览器中选择的本地图片并生成临时预览，但不会上传服务器；其他文件上传主要演示文件名和流程。
- 常规首图“轻动效”仍由网页动画模拟；故事模式保留 Seedance 实测完整动效，并作为同一长图式成稿中的动态段落呈现，不拆成另一份结果。
- 故事动漫长图先生成可编辑草图。用户确认标题和对白后，正式流程将确认文本连同构图约束提交 Seedream 做图字一体生成；最终预览直接使用文字已进入画面的栅格成图，不叠加网页文字层。成图后通过 OCR 与确认稿逐字比对；若用户再次改字，需要重新生成对应画面，而不是直接修改成图中的字符。
- 常规图文的首图不是独立素材，而是整体视觉方向的第一块模板；选择其他方向时，素色首图和照片首图的配色、构图、字形和叠色会同步变化。
- 审定稿文件解析、导出 Word、导出素材包和真实图表下载均为产品入口示意。
- 本期不采集任意外部公众号，不承诺全网实时数据，也不把模型风险提示包装成审核通过结论。
- 知识库一期按单位空间统一管理；页面中的多知识库选择是检索范围，不是权限模型。
- Codex CLI 应作为可横向扩容的 Worker 池承接任务，不按用户部署独立 CLI。模型负责理解与生成；文件解析、存储、排版、图像处理、规则校验和任务状态由平台服务承接。
