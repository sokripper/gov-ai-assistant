# 政府侧AI助手平台 · 交互原型交接说明

打开方式：浏览器直接打开 `index.html`（单文件，无依赖、无需服务端）。
目标视口：桌面 Web，基准 1440×900；已回归 1920×1080、1440×900、1366×768、1280×720、1024×768。

> 本原型仅用于设计验证与评审演示，**不作为生产前端源码**。生产前端按 React + TypeScript + Vite + Ant Design 重建。

分辨率策略：

- `≥1280px`：完整侧边导航和桌面多栏布局。
- `1024–1279px`：侧边导航自动收为图标栏，工作台侧栏缩窄，文档表格按优先级收起次要列。
- `<1024px`：不在本桌面原型的验收范围内；生产实现如需支持平板或 H5，应单独设计对应布局。

## 三、交互状态覆盖

| 状态 | 覆盖位置 |
|---|---|
| 默认 / Hover / Pressed | 所有按钮、卡片、表格行、导航项 |
| Disabled | 生成按钮处理中、二期功能占位卡（`.tool.soon`） |
| Loading | 问答检索骨架屏、工具处理分步进度、纪要生成 4 阶段、上传解析进度条 |
| Empty | 问答空态（示例问题）、工具结果区、纪要结果区、解析队列、筛选无结果 |
| Error / Fail | 问答无命中兜底、文档解析失败（含原因与重试）、删除二次确认 |

## 四、Mock 数据结构（生产接口对齐参考）

| 常量 | 含义 | 关键字段 |
|---|---|---|
| `KBS` | 知识库列表 | `id, t(名称), n(文档数)` |
| `TOOLS` / `TOOLS_SOON` | 工具清单 | `id, t, d, ic, mode(text\|file), hot` |
| `ASSIST` / `ASSIST_SOON` | 助手清单 | `id, t, d, g(分组), v(目标页)` |
| `QA_CASES` | 问答能力样例 | `match(关键词匹配), kb(检索范围), a(HTML), s(引用编号数组), fu(追问)` |
| `SRC` | 引用来源 | `t(文件名), kb, loc(页码位置), frag(原文片段), hl(高亮片段)` |
| `DOCS` | 文档列表 | `n, kb, tag, f(格式), sz, ck(切片数), up, dt, st(状态), cite, err` |
| `CHUNKS` | 知识切片 | `id, loc, cite, t(正文), off(是否停用)` |
| `ISS` | 校核问题 | `c(类型码), t(类型名), loc, old, new, risk, basis` |
| `TREND / TYPES / TOP10` | 看板数据 | 趋势、类型分布、被引用排名 |
| `flowState` | 跨页面流程状态 | `handoff(问答移交), draft(当前文稿), review(校核稿), transcript(转写稿)` |

文档状态枚举 `ST`：`ok 已生效 / parsing 解析中 / queue 排队中 / fail 解析失败 / off 已停用`
校核问题类型：`fmt 格式规范 / typo 文字差错 / word 用语规范 / pol 政治表述`

## 五、需要真实 API 的位置

| 位置 | 函数 | 需替换为 |
|---|---|---|
| 问答发送 | `qaSend()` | 流式问答接口（豆包）+ VikingDB 检索，返回答案与引用 |
| 引用溯源 | `showSrc()` | 按切片 ID 取原文片段与页码 |
| 工具执行 | `wbRun()` / `ftRun()` | 规则排版／用语规则 + 文本模型／文档解析／OCR／ASR 等不同处理接口 |
| 写作对话 | `wSend()` | 多轮对话接口，需回传定位到段落的修改结果 |
| 校核采纳 | `issAct()` | 采纳后回写文稿，服务端维护修订版本 |
| 纪要生成 | `mRun()` | ASR 转写 + 纪要结构化抽取 |
| 看板数据 | `ROUTES.kb.html()` | 统计接口，指标与图表数据 |
| 文档列表 | `docRows()` | 分页 + 筛选查询接口 |
| 上传解析 | `qPush()` | 分片上传 + 解析任务轮询／WebSocket 推送进度 |
| 切片治理 | `chToggle()` | 切片启用/停用接口，需同步 VikingDB 索引 |

## 六、当前 Demo 已贯通的状态流

| 起点 | 实际可演示流转 | 刷新后 |
|---|---|---|
| 知识库问答 | 真实按提问关键词与所选知识库匹配样例；未命中时阻止无依据生成；答案、问题和引用可携带到公文起草 | 恢复初始样例 |
| 写作助手 | 要素表单生成对应文种草稿；对话修改会更新右侧文稿；当前文稿可原样送入校核 | 恢复初始样例 |
| 公文校核 | 从当前稿件动态生成问题；采纳会形成修改稿，忽略会保留风险；可同步回写写作台 | 恢复初始样例 |
| 录音转文字 | ASR 结果可携带到会议纪要，作为已载入的转写稿继续生成 | 恢复初始样例 |
| 上传文档 | 排队 → 解析中 → 生效／失败；生效文档进入列表、详情和问答样例，失败项可重试 | 恢复初始样例 |
| 文档治理 | 搜索、组合筛选、启停、删除、批量停用、失败重试、切片停用均有前端状态变化 | 恢复初始样例 |
| 最近会话 | 可恢复对应工作台，并支持重命名、二次确认删除 | 恢复初始样例 |

## 七、必须在生产实现的视觉效果

- 公文版式：红头版头、仿宋_GB2312 正文、成文日期右空 4 字（`.doc-title` `.doc-body` `.paper`）
- 校核标注四色体系与「已采纳」绿色态（`.mk` 系列）
- 文档状态五色标签体系（`.tag` 变体）
- 解析队列进度与失败原因展示

## 八、仅为原型演示、不必照搬

- 所有示例数据、人名、单位名、文号均为虚构
- 分页只提供第 1 页数据；后续页需接真实分页接口
- 上传区点击即载入预置示例文件，不读取真实文件
- 导出 Word / 下载 / 推送待办均为提示，不产生真实文件
- 图表为纯 CSS 绘制，生产建议改用图表库以支持交互与下钻

## 九、一期口径提醒

- **不做权限体系**：知识库统一入库管理，无可见范围、部门隔离、个人库；问答页的知识库多选是**检索范围**而非权限
- 底层模型：豆包系列；知识库：豆包 VikingDB（备选 RAGFlow）
- 基础模型只承担文本理解与生成；格式排版、确定性校验、OCR、ASR、文档解析、检索与状态治理不能假设由基础模型单独完成
- 二期功能在广场中以虚线占位卡呈现，点击提示「即将上线」
